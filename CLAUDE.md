# Repository instructions

Read and follow the complete `AGENTS.md` in this repository before responding or editing.
It defines the Korean interview process, required response format, evidence rules,
art direction, validation and GitHub Pages deployment. For visual work also read
docs/ART_DIRECTION.md, docs/ART_STYLE.md, docs/ART_RECIPES.md,
docs/ART_DECISIONS.md and docs/ART_REVIEW.md completely. Preserve meaning and
visual impact, reuse one symbol per subject, and do not restart the style interview.
Run npm run check-art; it does not replace live visual and motion review.
User color choices are free in content/theme.json. Read docs/THEME_GUIDE.md;
preserve the shared CSS/shader token connection, not the default hues.
Do not skip the interview
when personalizing the sample. The user's direct instructions take precedence.
