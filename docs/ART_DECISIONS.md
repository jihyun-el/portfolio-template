# 아트 판단 기록 — 반복하지 않을 실패

이 표는 기존 제작 과정에서 확인된 패턴을 개인 정보 없이 정리한 것이다. 모든 기법의 영구 금지 목록이 아니다. 수락·기각은 해당 장면과 당시 목적에 대한 판정이다. 최신 사용자 요청이 바뀌면 새 비교와 근거를 남긴다.

## 유지할 방향

| 판단 | 적용할 원칙 | 과도한 일반화를 막는 경계 |
|---|---|---|
| 빛의 고리와 일관된 신호 색표가 중심 장면을 묶음 | 하나의 큰 조형, 같은 빛·명암 규칙 | 모든 자료와 글자를 무지개색으로 칠하지 않음 |
| 원본색 조각이 잉크 구조 안에서 변하는 장면이 전달력을 가짐 | 실제 입력과 처리 표현의 대응, 변경점이 주인공 | 원본색은 의미 있는 이미지·토큰에 제한 |
| 문서·필기·도장으로 행위가 읽히는 장면이 유효 | 내용에 맞는 사물과 사건 | 모든 실험을 장부·연구 노트로 만들지 않음 |
| 같은 기기·처리기·결과를 전역에서 같은 심볼로 | 한 원본, 작은 크기를 위한 별도 간결화 | 큰 장면을 통째로 축소하지 않음 |
| 시차·카메라 방향·같은 대상의 착지가 장면 관계를 드러냄 | 의미 있는 공간 이동과 전환 | 모든 메뉴에 의미 없는 확대를 붙이지 않음 |
| 약한 깊이 감쇠·먼지가 공간을 보조 | 원근·거리·가림의 보강 | 미세 효과만 넣고 극적인 변화라고 보고하지 않음 |
| 숫자·단위의 고정폭 글꼴과 약한 보랏빛 중립색 | 정밀한 계측감과 통일된 표면 | 한글 띄어쓰기까지 모노로 벌리지 않음 |
| 전후의 원인과 결과가 같은 장면에서 읽힘 | 주장을 담는 사건을 직접 그림 | 메커니즘 도식이 언제나 최선이라고 가정하지 않음 |
| 원시 신호를 정돈해 의미가 읽힘 | 사건의 사실성, 표시의 절제 | 실제 실패를 성공으로 바꾸거나 수치를 꾸미지 않음 |
| 단순한 2D 비교가 억지 3D보다 명료함 | 표현 차원은 내용에 맞게 | 3D로 그렸다는 사실 자체를 성과로 취급하지 않음 |

## 기각되거나 되돌린 접근

| 실패 | 왜 실패했는가 | 다음 에이전트의 조치 |
|---|---|---|
| 커밋 양을 은하·점의 군집으로 보여 줌 | 화려하나 기여·판단이 그림에서 읽히지 않음 | 기여의 실제 행위와 연결된 장면으로 구성 |
| 옅은 카드·색 띠·아이콘·칩·화살표 나열 | 정돈되지 않은 대시보드 문법, 조형 부재 | 한 장의 큰 물체·명암·사건부터 설계 |
| 같은 빈 상자에 후보 이름만 바꿈 | 형태·규모·작동 차이가 드러나지 않음 | 실제 역할을 보존한 별도 실루엣과 밀도 |
| 일반적인 작은 그림 셋과 화살표 | 전체 제품을 이끈 일이나 부품의 맞물림을 전달 못 함 | 하나의 물체 안에 포함·이동·변화를 구성 |
| 회색 입체 띠·점구슬·추상 격자 | 실체와 의미가 모호하거나 장난감처럼 보임 | 핵심 대상을 알아볼 형태로 다시 그림 |
| 구조는 작고 빈 연결 구간은 김 | 미완성 시안처럼 보이고 주인공이 없음 | 구성 비율과 덩어리부터 고침 |
| 모든 요소를 밝게·블룸을 강하게 | 받침대가 데이터만큼 튀고 미감은 개선되지 않음 | 실루엣·배치·밀도 → 명암 → 후처리 순 |
| 반사 바닥·광원·유리·보케를 덧댐 | 해당 시안에서 의미보다 효과가 앞섬 | 기본 해법으로 재제안하지 않음. 꼭 필요하면 새 근거와 독립 비교 |
| 요청 없이 전체 3D를 붉은 단색으로 치환 | 당시 선택한 빛의 문법을 잃음 | 사용자 팔레트를 임의로 덮어쓰지 않음. 사용자가 붉은 계열을 고르는 것은 허용 |
| 글자까지 신호 그라디언트 적용 | 신호·타이포 역할 혼합, 과장된 인상 | 제목은 제한된 단색, 라벨은 잉크 |
| 과한 장식용 제목 글꼴과 거대한 글자 | 글꼴·범위·크기의 조합이 화면에서 맞지 않음 | Pretendard + 제한된 Mono, 위계·자간·줄바꿈 조정 |
| 설명 문장을 더해 모호함을 수습 | 그림 자체가 전달해야 할 일을 글에 떠넘김 | 대상·비교·사건·카메라를 다시 설계 |
| 정돈된 비교를 굳이 3D로 변경 | 시인성 저하, 원근이 차이를 가림 | 명료한 2D 유지 가능. 사이트의 선·색 문법만 맞춤 |
| 실제 데이터의 모든 프레임·입자를 그대로 재생 | 지터·속도·밀도가 이해를 방해 | 사실을 보존한 대표 샘플·평활·속도 조정 |
| 출력값을 별도 앞줄에 놓음 | 원근에서 원래 대상과 위치가 어긋남 | 값과 빛을 그 대상 자체에 붙임 |
| 전체 구조 샷을 모든 단계에 재사용 | 실제 변경점이 작고 변화를 기억해야 이해됨 | 변경점 확대, 문맥 약화, 이전 윤곽 보존 |
| 선택지 전체를 한꺼번에 재배열 | 사건이 우왕좌왕하고 기준이 사라짐 | 기준 글자 고정, 한 쌍씩 일관된 레인으로 이동 |
| 3D 선과 DOM 라벨을 따로 계산 | 시차·리사이즈에서 끝점이 떨어짐 | 같은 프레임·카메라의 화면 좌표로 연결 |
| 원근의 작은 오차마다 꺾인 선 생성 | 불필요한 턱·계단이 생김 | 공통 라우팅과 작은 편차 정렬 |
| 작은 심볼로 복잡한 홈 그림 축소 | 작은 크기에서 뜻모를 얼룩 | 최소 크기 전용 심볼을 한 원본으로 재사용 |
| 전환 애니메이션 중 고정 UI 높이 측정 | 버튼이 엉뚱한 위치나 화면 밖에 고정 | layout 좌표와 실제 착지 좌표를 구분 |

## 판정이 끝나지 않은 것을 다루기

- 어떤 기법을 수락했다고 그 장면의 모든 후속 변경까지 수락한 것은 아니다.
- 원본색·잉크 구조의 특정 시안은 수락되었지만, 같은 전체 구조를 다른 판단 장면에 반복한 후속 시안은 의미 전달 문제가 남았다. 기법과 완성도를 분리한다.
- 어떤 수치 변환의 효과가 안 보인다는 지적이 남았다면 이를 대표 성공 예로 쓰지 않는다. 원인의 물리적·시각적 차이가 보이는지 다시 진단한다.
- 독립적인 읽기 검사 통과는 사용자 미감 수락과 다르다. 기능·의미·미감·사용자 수락 상태를 따로 남긴다.
- 과거 특정 화면에 적합했던 종이 문법이 다른 화면에서는 번잡했다. 전역 일관성은 모든 화면에 같은 재질을 강제하는 것이 아니다.

## 새 판단을 남기는 형식

```text
대상과 주장:
유지할 기준:
바꾼 축:
관찰한 문제:
시안의 차이:
의미 검사 결과:
밝음/어두움·창 크기·동작 검사:
사용자 판정: 수락 / 기각 / 일부 수락 / 판정 전
정확히 수락한 범위:
다음 수정에서 보존할 것:
```

새 기록에는 현재 템플릿의 공개 가능한 변경만 쓴다. 개인 인터뷰, 비공개 원본 경로, 외부 프로젝트의 내부 수치와 원문 대화를 이 문서에 복제하지 않는다.

## 첫 프로젝트의 양자화 견본

- 대상과 주장: 같은 합성 지형의 계단면과 연속면을 비교하는 설명용 도식. 실제 모델의 성능이나 작성자의 경력을 주장하지 않는다.
- 사용자 지정 범위: 새 첫 프로젝트의 메인 아래쪽에 양자화 도식을 두고, 선지 점·선택 고리·선지 순환을 제거한다. 기존 두 프로젝트는 뒤로 한 칸씩 옮긴다.
- 유지한 기준: 기존 지형·입체 표면·잉크와 원본색, 사이트의 글꼴·레일·테마 토큰. 작은 노트북 창에서는 사라진 선지 영역의 빈 공간까지 카메라에 포함하지 않는다.
- 상세 심볼 원본: `src/components/quantization-mark.tsx`. 연속 곡선과 계단선을 겹친 2D 실루엣을 76·104·140px 크기에서 공유한다.
- 대체 표현: 같은 `scene.js`의 형상에서 두 테마의 정지 SVG를 생성한다.
- 실시한 검사: 다크·라이트, 1440×668·1440×900·960×1080·1110×668·390×844의 홈·상세, 프로젝트 탐색·직접 상세 주소·돌아가기, 움직임 줄이기, WebGL 실패 시 정지 도식. `/portfolio`와 `/portfolio-template`의 빌드·경로 연결을 확인했다.
- 사용자 판정: 수락. 새 첫 프로젝트의 양자화 랜딩, 선지 순환 제거, 상세의 2D 심볼, 기존 프로젝트 순서 이동, README 다크 랜딩 이미지 교체가 수락 범위다. 이 범위를 다른 장면의 미감 수락으로 확대하지 않는다.
