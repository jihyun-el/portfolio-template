# 아트 디렉션 읽기 순서

이 템플릿의 아트 기준은 아래 문서 전체다. 내용 교체를 이유로 스타일 인터뷰를 처음부터 다시 시작하거나 기준을 낮추지 않는다.

1. [ART_STYLE.md](ART_STYLE.md): 아트의 목표, 조형·색·심볼·연출·단순화의 고정 원칙
2. [ART_RECIPES.md](ART_RECIPES.md): 실제 구현 방법과 실패 진단
3. [ART_DECISIONS.md](ART_DECISIONS.md): 수락·기각·적용 범위와 반복하지 않을 실패
4. [ART_REVIEW.md](ART_REVIEW.md): 제작·검수·보고·변경 기록의 규격
5. [THEME_GUIDE.md](THEME_GUIDE.md): 사용자가 자유롭게 고르는 색 토큰과 그림 팔레트
6. [art/style-contract.json](art/style-contract.json): 토큰 연결·폰트·문서 검사 규격

핵심은 **한눈에 의미가 읽히면서 충분히 미려하고 인상적인 그림**이다. 화려함을 줄여 모호함을 해결하거나, 설명이 맞다는 이유로 투박한 조형을 완료 처리하지 않는다.

현재 템플릿의 `orbit`, `layers`, `flow`, `none`은 추상 장식 예시다. `quantization`은 같은 합성 지형의 계단면과 연속면을 비교하는 설명용 견본이며, 실제 모델의 측정값이 아니다. 첫 프로젝트의 메인 아래쪽에 배치하고, 상세에는 연속 곡선과 계단선을 겹친 작은 2D 심볼을 사용한다. 선지·선택 고리·선지 순환은 포함하지 않는다.

의미 있는 도식·종이 장면·연속 카메라가 모두 구현되어 있거나 현재 샘플 전체가 사용자 미감 수락을 받았다는 뜻이 아니다. 실제 프로젝트를 인터뷰한 뒤 필요한 그림을 위 기준으로 확장한다.

색·폰트·문서 연결은 `npm run check-art`로 검사한다. 이 명령은 의미·미감·동작을 자동 판정하지 않는다. 실제 움직이는 미리보기 검수가 별도로 필요하다.
